## 为什么保留现有架构

数据流：官方来源 → 定时抓取/队列 → R2 不可变原文 → 确定性抽取或现有双模型一致性核验 → D1 候选与字段发布 → 完整目录版本 → 网站。

R2 保存“当时实际看到的内容”，D1 保存“哪个字段由哪段内容支持”。二者分开，使失败重试与历史审查不需要覆盖旧证据。新 observation 是再次取得同一内容的独立收据；304 只说明缓存可复用，不能充当新正文复核。

自动化权限也分层：新来源可以自动登记，但不能凭自身填写的域名给自己授权；字段自动发布必须通过官方归属、引用、无冲突、时间和完整性检查。AI 可提出候选，模型自称正确不构成证据。没有增加模型预算、并发上限或购买新服务。
