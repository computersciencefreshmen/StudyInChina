## 为什么这样重构

项目已经有较成熟的 Next.js 前台、JSON 兼容目录、Cloudflare 采集与 D1 发布链路。此次采用渐进重构，把同一条证据的含义贯穿数据、API、页面和对比，不更换已经工作的基础架构。

关键区分有三层：

1. **项目身份**：确实存在这个项目，适合保留发现入口。
2. **招生周期**：这个学期何时开始申请、何时截止；只有未来截止日不能推断已经开放。
3. **事实有效期**：费用、要求和入口多久以前核验；日期需要重新检查并不表示学校停办。

原始数据可以缓存，但“今天是否还能申请”的判断必须重新计算。详情及其搜索元信息现在按请求评估，API 的缓存不能跨越中国零点；长期打开的收藏页也会在午夜与重新可见时刷新。

完整方案及取舍：[升级设计](../plans/2026-09-16-decision-platform-upgrade.md)。

## 前后端的实质改造

### 申请者可见的变化

- 学校、项目、奖学金详情上方显示记录核验日、下次复核日和评估日期；招生周期单独显示，不与申请截止混用。
- 一键跳到官方证据；项目详情不遗漏所列周期来源。
- 筛选页解释未公布日期与关闭申请的区别，支持快速回到全部状态。
- 收藏比较显示招生状态、周期、核验和复核日期。历史参考学费、冲突值及过期字段不会冒充当前事实。
- 对比页从日期重新计算申请状态，不相信加载时的旧状态；中国午夜和页面重新可见时刷新。过期费用、学制和授课语言统一隐藏。

### 工程修复

- JSON、D1 视图与筛选统一使用中国日历：未来 opening 优先于 rolling；只知道 closing 时为 dates-published。
- 新增 Catalog 迁移 `0011_application_state_calendar.sql`，保留旧迁移的不可变历史。
- 公共 ETag 对应实际 JSON 响应；校验路由和参数后才可能返回 304。
- 缓存的新鲜和允许旧副本窗口均在中国零点前结束；错误响应不缓存。
- 自托管 production 不允许草稿预览；显式 Vercel Preview 保留。
- 链接扫描同主机串行、不同主机公平调度并报告进度；响应体清理失败不吞掉已确认 HTTP 状态。
- 全量审计和其测试接入现有 data-health/CI 工作流。结构检查不会把“没有招生”当作代码失败。

## 依赖与安全

官方审计发现原 Next.js 16.3.0 在 Windows 服务器和 AVIF 图片处理方面存在严重漏洞，已升级至 16.3.5；同步更新 eslint-config-next、Vitest 4.1.11、Wrangler 4.131.2 及有问题的间接依赖。最终生产及开发依赖审计均为 0 已知漏洞。[Next.js 官方公告](https://github.com/vercel/next.js/security/advisories/GHSA-p293-qw3h-jr36)

这表示当前依赖库的已知漏洞扫描通过，不表示完成了渗透测试或对所有生产配置作出安全认证。

## 尚未完成的核验与发布边界

1. **全量扫描不等于全量官网逐字段复核。** 仍有 4,631 条实体跟进任务，涵盖缺失字段、过期证据、共享来源及历史截止日；它们不等于 4,631 条错误。
2. **数据深度仍不足。** 1,109 个项目缺要求，448 缺学制，181 缺授课语言；82 个潜在可行动旧周期应优先复查。原始事实存在也不意味着当前可展示。
3. **链接仍需修复。** 17 个确认失效 URL 和 240 个访问不确定 URL 均保留在清单，部分是历史溯源链接；已修当前学校入口不意味着旧 URL 恢复。
4. **D1 切换暂不具备充分证据。** 新迁移尚未应用远程，完整目录状态筛选还需测量性能，原有 Shadow 对比、备份恢复与回滚门禁应保留。
5. **外部 AI 未提供事实。** 尝试了已安装 Claude Code 的 MiniMax-M2.7 调用，只开放网页工具、设置费用上限；配置的本地 API 代理拒绝连接，实际费用 0，接受事实 0。所有已落库事实来自独立官方来源核验。
6. **生产网站未更新。** 当前交付为本地代码、数据、报告和预览；原有未跟踪资产保留，无删除、合并、推送或生产切换。
