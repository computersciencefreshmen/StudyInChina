# Keep real captures usable when navigation ancestry exceeds its budget

Read-only production evidence established the immediate failure: the NENU
bachelor guide has ten discovered parents, the master and doctoral guides nine.
The old recursive recordTargets throws after eight visited sources. A guide can
therefore finish its real fetch, save current raw/text and an observation, then
throw before normal PDF-link discovery. The bachelor guide has the exact stored
error source_parent_partition_required. Raising the cap or treating every
navigation parent as programme applicability would hide the problem.

The new reader keeps the root's directly bound targets first and traverses a
breadth-first acquisition graph: at most eight source nodes, depth two, sixteen
frontier reads, 256 parents per lineage and 256 KiB per lineage/frontier object.
Every direct target must agree with its SQL identity/scope/owner columns, and
root, node and target must share a school in the current control scope. An
ancestor contributes only program candidates, not scholarships/cycles or facts.
Its receipt must be a real content-addressed frontier with the parent source,
current parent raw hash and exact child URL, within its approved hosts.

The former lineage format has one latest frontier hash for many parents. That
hash cannot prove every historical edge. Newly discovered edges retain a
parentFrontiers mapping; existing parent IDs are preserved. Legacy latest-only
references are checked against the actual frontier for that exact parent. No
unverified edge is accepted merely because it appears in an old parent list.

Budget, depth, missing/malformed/changed receipt and ownership failures remain
explicit pending edges. queueExtraction retains an immutable checksum-bound
held manifest and an idempotent event before using the verified subset. The
manifest states applicabilityEstablished:false and catalogueComplete:false.
The reader never calls a partial graph a complete school or invents a programme
condition. It does not reverse edges or attach common annual policies.

The read-only recordTargets wrapper remains available to processors. Original
request/job keys, unknown/STOP protection, model admission, canonical publisher,
fact dates and control flags are unchanged. The successful fetch can now finish
and its ordinary discovery frontier can register a newly linked official PDF.
Existing failed captures are not manually reset by this change; normal captures
must succeed before their acquisition error clears.

Regressions cover ten real receipt-backed parents, explicit omitted-edge holds,
legacy latest-only provenance, cross-school/old-scope rejection, mutated frontier
or parent snapshot, cycles/depth and an actual capture-to-frontier-to-PDF-source
registration with zero model attempts. Same-scope direct evidence is retained
without accepting arbitrary navigation as eligibility or annual applicability.
