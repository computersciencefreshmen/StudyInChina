Scholarship

来源 : 国际教育学院     作者 :      时间 : 2025-01-09

Zhejiang Provincial Government Scholarship for International Students

RMB 30,000 for Type A, RMB 20,000 for Type B


Communication University of Zhejiang Scholarship for Undergraduate

There are 3 types: Type A, Type B and Type C


Type A: 100% of the tuition fee (upper limit RMB 18,000)

Type B: 50% of the tuition fee (upper limit RMB 9,000)

Type C: 30% of the tuition fee (upper limit RMB 5,400)


Communication University of Zhejiang Scholarship for Postgraduate

100% of the tuition fee
