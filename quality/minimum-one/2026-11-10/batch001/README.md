Supplementary official HTML establishes institutional context and USTC's bachelor's degree. No browser cookies, credentials or paid model calls were used.

`evidence-index.json` maps immutable object keys to gzip archives, recording both compressed and original hashes and lengths. The USTC PDF has a complete native text extraction with page boundaries, produced by the installed MiKTeX-distributed **Poppler pdftotext 24.04.0**; its actual version output is archived. A separate agent checked the PDF's rendered first page and the HTML rows. The archived source-review artifact records this cross-check and its limitations; it does not claim human approval or a formal paid-model review.

`export.json` contains exact located name, degree and international-scope quotes, null year/intake scope, the reviewed proposal fingerprints, current baseline hash and fixed-school-scope hash. `identity-import-receipt.json` was generated by the existing importer, not hand-authored. Its repository-relative path matches the existing Next.js tracing glob. The four affected canonical files are programs, sources, identity acceptances and identity bindings; no unrelated collections were rewritten.

`report.json` compares the production-safe projections for November 10 and 11. Directory programmes increase from 989 to 1004; schools with directory programmes increase from 223 to 226; schools without programmes decrease from 55 to 52. Current-fact counts remain unchanged. Integrity does not certify a complete school catalogue or an open application opportunity.

`replay-verification.json` records an independent offline replay from the exact Git baseline using only the archived evidence. It verifies every compressed/raw checksum and reproduces the import receipt and all four canonical outputs. To audit the batch, reconstruct the baseline with `git show`, call the existing `importIdentityCandidates` export with `export.json`, the baseline acceptance/binding ledgers, the stored receipt's `acceptedAt`, this receipt's full repository-relative path, and an artifact reader that verifies and decompresses `evidence-index.json`. Do not rerun the writer against the already-expanded current catalogue: the baseline hash guard intentionally rejects that.

This local application is not a production-publication receipt. CI, build tracing and scoped post-deployment reads must still confirm the same published commit. No production-wide smoke or load test is part of this batch.
